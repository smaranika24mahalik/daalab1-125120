## 📚 About Design and Analysis of Algorithms (DAA)

**Design and Analysis of Algorithms** is a foundational branch of Computer Science focused on creating efficient computational methods to solve complex computational problems and measuring their runtime and space performance.

### 💡 Core Paradigms Covered
* **Divide and Conquer:** Breaking a problem into smaller sub-problems, solving them recursively, and combining their results (e.g., Merge Sort, Quick Sort).
* **Greedy Approach:** Making locally optimal choices at each step with the goal of finding a global optimum (e.g., Fractional Knapsack, Prim's/Kruskal's Algorithm).
* **Dynamic Programming:** Storing results of overlapping sub-problems to avoid redundant calculations (e.g., 0/1 Knapsack, Longest Common Subsequence).
* **Backtracking & Branch and Bound:** Systematically searching state spaces for constraints and optimization problems (e.g., N-Queens, Graph Coloring).

### ⏱️ Theoretical Foundations
Each algorithm in this repository is analyzed using asymptotic notations:
* **$O$ (Big-O):** Upper bound (Worst-case complexity).
* **$\Omega$ (Big-Omega):** Lower bound (Best-case complexity).
* **$\Theta$ (Big-Theta):** Tight bound (Average/Exact complexity).
